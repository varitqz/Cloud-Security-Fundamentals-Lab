# Changelog

## v5.0.0 — Command Center

### Added
- Unified Command dashboard and nine-view application shell.
- End-to-end synthetic attack chain across `SigninLogs`, `AuditLogs` and `AzureActivity`.
- Local educational KQL runtime and query explainer.
- Eight bundled detection templates and local detection-rule persistence.
- Synthetic alert creation from query results.
- Incident Response Center with evidence, notes, assignment, containment and resolution.
- Cloud Posture module with five seeded findings, remediation and dynamic local Secure Score.
- Bicep Security Review with a local static scan and segmented VNet visualization.
- Portfolio Casebook with exported Markdown evidence and JSON state export.
- XP, levels, achievements and skill-matrix progression.
- Command palette (`Ctrl + K`), reset flow, toasts and keyboard-friendly interactions.
- Radar, scanline, pipeline, reveal, ripple and pointer-light visual effects.
- Responsive layout and reduced-motion handling.

### Expanded
- Certification engine remains at 100 original questions, now integrated into global progression.
- Identity Review now calculates and displays derived access risk and supports local remediation simulation.
- Zero Trust Investigation now correlates sign-in, identity and Azure control-plane evidence.
- Detection catalog expanded to eight scenarios.
- Documentation reorganized into architecture, detection catalog, lab guide and portfolio positioning.

### Preserved from v1.0
- Local-first / zero-cost operating model.
- AZ-900 and SC-900 training focus.
- Entra directory roles vs Azure RBAC distinction.
- Identity & Access Review concept.
- Zero Trust investigation concept.
- KQL and Bicep learning focus.
- Black/red `BUILD. DETECT. DEFEND.` visual identity.
